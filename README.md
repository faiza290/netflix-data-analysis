# Netflix Content Analysis 🎬

Analyzed 8,800+ Netflix titles using Python and Power BI.

## Tools Used
Google Colab, Python (pandas), Power BI Desktop

## Key Insights
- 69.6% of Netflix content is Movies, 30.4% TV Shows
- United States produces the most content by far
- Content grew rapidly after 2015, peaking in 2019-2020
- TV-MA is the most common rating — Netflix skews mature

- `netflix_cleaned.csv` — cleaned dataset
